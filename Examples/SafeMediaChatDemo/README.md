# SafeMediaChatDemo

This is a package-based demo snippet instead of a full Xcode project. Copy `Sources/SafeMediaChatDemoView.swift` into an iOS or macOS app target that depends on:

- `SafeMediaKit`
- `SafeMediaKitTesting`

The demo uses safe, generated placeholder images and mock analyzers to show:

- safe media
- sensitive media with reveal/report
- unavailable analysis

No explicit media is included.
